# Team FullMoon

Team FullMoon is a small independent game studio. We create games with exciting action, memorable worlds, and a strong atmosphere. Our team is currently testing ideas and building early versions of new projects.

## Our projects

### Survivor Arcade

Survivor Arcade is a fast action game where players must survive, improve their abilities, and face new challenges. The game is still in development, so more information and gameplay videos will be shared later.

We are also exploring other arcade game ideas. New projects will be announced when they are ready.
